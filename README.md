# PipesApp

Aplicación de práctica de la Sección 12 del curso de Angular. En esta sección se estudian los pipes integrados de Angular para transformar valores al presentarlos en las plantillas y la configuración de internacionalización.

## Temas

1. `DatePipe`
2. `UpperCasePipe`
3. `LowerCasePipe`
4. `TitleCasePipe`
5. `CurrencyPipe`
6. `DecimalPipe`
7. `PercentPipe`
8. `I18nPluralPipe`
9. `I18nSelectPipe`
10. `JsonPipe`
11. `KeyValuePipe`
12. `SlicePipe`
13. `AsyncPipe`
14. Internacionalización de Pipes y de la aplicación

## Desarrollo

Requiere Node.js y npm. Instala las dependencias e inicia el servidor:

```bash
npm install
npm start
```

La aplicación queda disponible en `http://localhost:4200/`.

## Validación

```bash
npm run build
npm test -- --watch=false
```

## Ramas

- `seccion12`: ejercicios y ejemplos de Pipes.
- `master`: versión estable más reciente.

No agregues archivos `.env` ni claves locales al repositorio.
